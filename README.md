# Greeting Application

A simple Python application that greets and says goodbye to customers by name.

## How to Run

Run the application:
```bash
python greeting.py
```

You will be prompted to enter your name, and the application will return both a greeting and a goodbye message.

## Running Tests

Run the tests:
```bash
python test_greeting.py
```

Or using unittest discovery:
```bash
python -m unittest test_greeting.py
```
